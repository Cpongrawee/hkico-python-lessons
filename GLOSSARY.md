# HKICO Python Lessons

Teaching materials for preparing students for the HKICO Heat Round (Python), delivered as Colab notebooks.

## Language

**Mock Paper**:
A full practice exam, either a mock or a real past paper (e.g. Mock 1, Mock 2), that becomes one Lesson notebook.
_Avoid_: mock test, paper

**Lesson notebook**:
The notebook made from one Mock Paper. It stands alone: it never assumes the student has seen another Lesson notebook, and it carries no class date and no time limits, because one notebook may be taught over several classes and to many groups, and each ข้อ takes as long as the students need.
_Avoid_: mocktest_lesson, worksheet

**ข้อ** (Question):
A single exam question within a Mock Paper; some are grouped into one section when they share the same code (e.g. ข้อ 9–11).
_Avoid_: problem, item

**เฉลย** (Answer section):
The part of each ข้อ that students must not open until the teacher says so; it holds the answer and why each option is right or wrong. It comes straight after the student's own answer, before the concept is taught.
_Avoid_: solution, key

**อ่านเพิ่ม** (Further reading):
The last part of a ข้อ, after the experiments: one or two links to the specific chapter or section of a free, English-language reference that explains the concept tested, each with a short Thai note on what to read.
_Avoid_: reference, resource link

**กับดัก** (Trap):
A detail in a ข้อ planted to catch students who read too fast, such as a misspelled name, a missing colon or wrong indentation. The answer is always what Python actually does with the code as printed.
_Avoid_: typo, mistake

**การทดลอง** (Experiment):
One guess-then-run exercise in a ข้อ's 🧪 section. The student writes a specific guess, runs the cell, then writes whether the guess was right and why. Each ข้อ has seven, climbing from easy to hard: 🟢 the paper's code as printed, 🟢 change one value, 🟡 make a wrong option the right one (two of these), 🟡 edge cases, 🔴 fix broken code, 🔴 make up an exam question.
_Avoid_: exercise, lab, activity
